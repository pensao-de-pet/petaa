# petaa
Sistema acadêmico da turma de Ciência da Computação, desenvolvido pelo grupo Pensão de Pet.

Inspirado no SIGAA, o petaa nasce para resolver problemas reais do nosso dia a dia como estudantes: organizar disciplinas, materiais, monitorias e grupos de estudo em um só lugar. O projeto também é a nossa forma de aprender na prática, crescendo junto com o curso.

🚧 Projeto em fase inicial. A estrutura e as tecnologias ainda estão sendo definidas.

Objetivos
Construir, ao longo do curso, um sistema útil para a nossa própria turma.
Praticar trabalho em equipe com ferramentas reais (Git, GitHub, revisão de código).
Aplicar o que aprendemos em cada disciplina, aumentando a complexidade aos poucos.
Roadmap

O projeto evolui conforme as disciplinas que vamos cursando.

Fase | Quando	| O que entra
1	| Estrutura de Dados | Cadastro de disciplinas e professores, grafo de pré-requisitos, armazenamento simples em arquivo
2	| Banco de Dados | Banco relacional, banco de provas e materiais, avaliação de disciplinas
3	| Redes / Web | Aplicação web, login de usuários, API, mural de grupos de estudo e monitoria
4	| Engenharia de Software | Testes automatizados, CI/CD, refatoração e arquitetura em camadas
